# Trademark

The code is Apache-2.0 ([LICENSE](LICENSE)). The license does not grant rights to the name
"Costura" or to the mark in `apps/web/public/brand/` (section 6 of the license). This page
says how they may be used.

## Allowed without asking

- Saying that a deployment, a fork, or a product is based on Costura, or that it is
  compatible with it.
- Using the name in articles, talks, tutorials, and comparisons.
- Running an unmodified release under its own name and mark.

## Not allowed

- Calling a modified build "Costura", or shipping it with the mark, in a way that makes
  it look like an official release. Rename the fork and replace the mark.
- Implying that the maintainers endorse, support, or operate a service they do not.
- Using the name or mark in a company, product, or domain name.

`COSTURA_BRAND_NAME` and `public/brand/logo.svg` exist so a fork or a deployment can show
its own name and mark.

Questions go to a GitHub issue. The maintainers in [GOVERNANCE.md](GOVERNANCE.md) speak for
the project.
